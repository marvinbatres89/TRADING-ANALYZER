# Trading Analyzer Pro V2.0 Base

Primera base modular del proyecto.

## Incluye
- Diseño profesional para teléfono.
- Conexión WebSocket pública con Deriv.
- Precios y gráfico en tiempo real.
- Reconexión automática.
- Lista alternativa de mercados.
- RSI, medias móviles, volatilidad y lectura inicial.
- Diagnóstico visible.
- PWA básica.

## Subir a GitHub
Sube todos los archivos conservando las carpetas `css` y `js`. Luego activa GitHub Pages desde la rama `main` y `/root`.

Herramienta educativa: no ejecuta operaciones ni garantiza ganancias.
